## 2026-09-16 現調報告書アプリの要件を確定

**決めたこと**

- スマホのブラウザで開くPWAとして作る。置き場所はVercel、鍵（合言葉）は付けない
- 流れは スタート → 顧客情報 → 外観4枠 → 不具合4枠（ページ追加可）→ 完成プレビュー → 完了
- 完了を押すと、サーバー経由で会社の固定アドレスへPDF添付メールを自動送信する。
  Googleドライブ保存とGmail下書きは見送った（理由は docs/adr/0001）
- 写真は長辺1600px程度に自動縮小し、報告書全体を5MB以下に収める
- ステータス（コメントボタン）の文言は依頼元待ちのため、仮にA/B/Cを置く
- 顧客ごとのデータ管理と見積もり統合は今回作らない。顧客名は最初から記録する

**次にやること**

- 仕様書は Issue #2、作業は Issue #3〜#15 の13件として発行済み（すべて `ready-for-agent`）
- 依存関係は GitHub の blocked_by で設定済み。いま着手できるのは #3（土台とトップページ）のみ
- `/implement` で #3 から順に進める
- 運用開始前に、送り先の会社アドレスとステータスの文言を差し替える

**未解決の問題**

- 送り先の会社アドレスが未定（仮置きで進める）
- ステータスの文言が未定（依頼元待ち）
- メール送信サービスは Resend が第一候補。無料枠の条件が未確認
