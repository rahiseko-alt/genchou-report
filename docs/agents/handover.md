- 写真は長辺1600px程度に自動縮小し、報告書全体を5MB以下に収める
- ステータス（コメントボタン）の文言は依頼元待ちのため、仮にA/B/Cを置く
- 顧客ごとのデータ管理と見積もり統合は今回作らない。顧客名は最初から記録する
