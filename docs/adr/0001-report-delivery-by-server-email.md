# 現調報告書の受け渡しは、サーバー経由の自動メール送信だけで行う

当初はGoogleドライブへの自動保存とGmail下書きの自動生成を想定していたが、
どちらも担当者ごとのGoogleログインを必要とし、書類の置き場所が担当者のアカウントに分散する。
担当者5人全員の成果物を1箇所へ集めたいという要件に対し、
「完了を押すと、サーバーが会社の固定アドレスへPDF添付メールを送る」形を選んだ。
担当者側のログインが不要になり、出口が1つに定まる。

## Considered Options

- **Googleドライブ保存＋Gmail下書き**: 担当者ごとのログインが必要。個人Gmailアカウントの場合、
  Gmailへの書き込み権限はGoogleの審査対象となり、審査前は定期的な再ログインが要る【曖昧・登録時に要確認】。
- **端末の共有メニューからGmailアプリへ渡す**: 登録も費用も不要だが、宛先が自動で入らず送信漏れが起きうる。

## Consequences

- 報告書は送付後、会社のメール受信箱にしか残らない。担当者の手元には残らない。
- メール送信サービスの契約が1つ増える。送信元は固定の差出人となり、担当者名は本文に入る。
- 添付の上限（25MB前後）に収めるため、写真は送信前に縮小する必要がある。
